# 基因分离定律的实质及应用

一生儿《高中生物一本通》· 必修 2

使用 AI 生成的豌豆、细胞与染色体素材，演示同源染色体分离、随机受精、自交与测交，并提供抽样实验和分步应用推理。

## 使用

公开网页：https://meiosis7.github.io/gene-segregation-interactive/

网页为纯静态页面。图示仅为教学示意；遗传概率的适用条件见页面说明。

## 源文件

源文件在 src，AI 素材及提示词在 assets。运行 python3 build.py 可重新生成内嵌素材的离线 index.html。运行 node --test model.test.cjs 检查遗传概率模型。
